# Historischer Qwen-TTS-Einzelinstaller

[Zur Installerübersicht](../README.md)

Der [Qwen-TTS-Installer 1.5](install-kienzlefon-qwen3-tts-v1.5.sh) war der bisherige Inhalt dieses GitHub-Repositories, Stand 13. August 2026. Bei der Veröffentlichungsvorbereitung wurde er unverändert aus dem Hauptverzeichnis hierher verschoben. Seine bisherige Git-Historie bleibt erhalten.

Dies ist ein historischer Einzelinstaller mit damaligen Plattform- und Laufzeitvorgaben. Für die aktuelle Kienzlefon-AI-Installation gelten die getrennten CUDA-/Backendinstaller beziehungsweise die AMD-Anleitung in der [aktuellen Übersicht](../README.md). Den alten Einzelinstaller nicht ungeprüft mit der aktuellen Runtime kombinieren. Es fand keine erneute Installation oder Hardwareabnahme dieses alten Stands statt.
